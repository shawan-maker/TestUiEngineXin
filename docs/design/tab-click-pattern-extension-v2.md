# Tab 点击模式扩展设计文档（v2）

## 1. 背景与问题

### 1.1 当前状态
`step_patterns.py` 仅支持一种 Tab 点击格式：
```python
# line 187-188
(rf'(?:点击|单击|点){Q}(.+?){Q}\s*tab',
 'click_tab', ('label',))
```

### 1.2 实际 Excel 用例中的写法
```
❌ 点击登录日志Tab标签      （无引号 + 中文后缀）
❌ 切换到登录日志标签页      （切换动词 + 中文后缀）
❌ 点击"登录日志"标签页      （引号 + 中文后缀）
❌ 选择登录日志              （无后缀，最简形式）
```

### 1.3 关键冲突：选项卡 vs Tab

**发现的冲突**：
- `选项卡` 在现有代码中是 **单选组（option-card）** 的语义
- `标签`/`标签页` 才是 **Tab 页签** 的语义

**歧义示例**：
```
场景 1: 点击登录日志选项卡
  → Tab 语义：切换到"登录日志"这个 Tab 页
  
场景 2: 在"登录日志"选项卡中选择"今天"
  → option_card 语义：在"登录日志"这个单选组中选择"今天"
```

**决策**：采用方案 A（移除 `选项卡`），确保零冲突风险。

---

## 2. 设计决策

### 2.1 选择方案 A 的理由

| 维度 | 方案 A（移除选项卡） | 方案 B（智能边界） | 方案 C（优先级策略） |
|------|---------------------|-------------------|---------------------|
| **安全性** | ✅ 零冲突 | ⚠️ 依赖复杂正则 | ⚠️ 依赖模式顺序 |
| **可读性** | ✅ 简洁 | ❌ 复杂 | ⚠️ 中等 |
| **维护成本** | ✅ 低 | ❌ 高 | ⚠️ 中 |
| **用户习惯** | ✅ `标签` 更常用 | ✅ 支持更多写法 | ✅ 支持更多写法 |
| **实现难度** | ✅ 简单 | ❌ 边界情况多 | ⚠️ 需文档说明 |

**结论**：方案 A 最稳健，用户如需 `选项卡` 作为 Tab 可通过 `l3_call` 或自定义模式支持。

### 2.2 Tab 后缀定义（方案 A）

| 后缀 | 示例 | 说明 |
|------|------|------|
| `tab` / `Tab` | `点击"登录日志"tab` | 现有模式，保留 |
| `标签` | `点击登录日志标签` | 新增，无引号 |
| `标签页` | `点击登录日志标签页` | 新增，无引号 |
| `tab页` | `点击"登录日志"tab页` | 新增，有引号 |

**明确排除**：`选项卡`（属于 option-card 语义）

### 3.2 新增模式详情

#### 模式 1：引号 + 中文后缀（最常用）

**位置**：`step_patterns.py:188` 之后（现有 `click_tab` 之后）

```python
# 点击/切换/选择 "XX" 标签/标签页/tab页（必须在通用 click 之前）
(rf'(?:点击|单击|点|切换到?|选择){Q}(.+?){Q}\s*(?:标签页?|tab页)\b',
 'click_tab', ('label',)),
```

**匹配示例**：
- ✅ `点击"登录日志"标签` → `label='登录日志'`
- ✅ `点击"登录日志"标签页` → `label='登录日志'`
- ✅ `切换到"登录日志"tab页` → `label='登录日志'`
- ✅ `选择"任务提醒"标签` → `label='任务提醒'`

**不匹配**：
- ❌ `点击"登录日志"选项卡` → 留给 option-card 判断
- ❌ `点击"登录日志"` → 无后缀，匹配通用 `click_btn`

---

#### 模式 2：无引号 + `Tab` 后缀

**位置**：模式 1 之后

```python
# 点击 XX Tab/Tab页（无引号，英文后缀）
(rf'(?:点击|单击|点)\s*([^{Q}]+?)\s*(?:[Tt]ab(?:页)?)\b',
 'click_tab', ('label',)),
```

**匹配示例**：
- ✅ `点击登录日志Tab` → `label='登录日志'`
- ✅ `点击任务提醒tab页` → `label='任务提醒'`
- ✅ `单击用户管理Tab` → `label='用户管理'`

**不匹配**：
- ❌ `点击登录日志Tab标签` → 留给模式 3
- ❌ `点击"登录日志"Tab` → 被模式 1 或现有模式匹配

**技术细节**：
- `[^{Q}]+?`：非引号字符（避免与引号模式冲突）
- `(?:[Tt]ab(?:页)?)`：匹配 `Tab`/`tab`/`Tab页`/`tab页`
- `\b`：单词边界，防止匹配 `Tab标签`

---

#### 模式 3：无引号 + 中文后缀

**位置**：模式 2 之后

```python
# 点击/切换/选择 XX 标签/标签页（无引号，中文后缀）
(rf'(?:点击|单击|点|切换到?|选择)\s*([^{Q}]+?)\s*(?:标签页?)\b',
 'click_tab', ('label',)),
```

**匹配示例**：
- ✅ `点击登录日志标签` → `label='登录日志'`
- ✅ `点击登录日志标签页` → `label='登录日志'`
- ✅ `切换到登录日志标签页` → `label='登录日志'`
- ✅ `切换登录日志标签` → `label='登录日志'`

**不匹配**：
- ❌ `点击登录日志选项卡` → 无匹配（留给 option-card 或其他模式）
- ❌ `在"登录日志"标签页中选择"今天"` → 无匹配（留给 option-card）

---

#### 模式 4：切换/选择 + 引号（无后缀）

**位置**：模式 3 之后

```python
# 切换到/选择 "XX"（无后缀，最简形式，行尾或标点）
(rf'(?:切换到?|选择){Q}(.+?){Q}(?:\s*$|(?=，|,|；|;))',
 'click_tab', ('label',)),
```

**匹配示例**：
- ✅ `切换到"登录日志"` → `label='登录日志'`
- ✅ `选择"任务提醒"` → `label='任务提醒'`
- ✅ `切换到"登录日志"，然后...` → `label='登录日志'`

**不匹配**：
- ❌ `在"项目"下拉框中选择"登录日志"` → 被 `el_select` 拦截（优先级更高）
- ❌ `点击"登录日志"` → 被 `click_btn` 拦截（优先级更高）

**技术细节**：
- `(?:切换到?|选择)`：限定动词，避免与 `click_btn` 冲突
- `(?:\s*$|(?=，|,|；|;))`：行尾或标点符号作为边界
- 不匹配 `点击`，因为 `点击"XX"` 可能是按钮

---

#### 模式 5：条件表达式扩展（可选）

**位置**：`step_patterns.py:78-79` 之后（现有 `conditional_click_tab` 之后）

```python
# 条件 + "XX" 标签/标签页/tab页（中文后缀）
(rf'如果{Q}(.+?){Q}.*?中.*?(?:数量|条数).*?(?:大于|>)\s*0.*?则点击{Q}(.+?){Q}\s*(?:标签页?|tab页)\b',
 'conditional_click_tab', ('tab_or_section', 'tab_label')),
```

**匹配示例**：
- ✅ `如果"消息"中条数大于0则点击"任务提醒"标签页` → `tab_or_section='消息', tab_label='任务提醒'`

**不匹配**：
- ❌ `如果"消息"中条数大于0则点击"任务提醒"选项卡` → 无匹配（选项卡排除）

**说明**：仅支持引号 + 后缀形式，无引号变体暂不支持（条件表达式已足够复杂）

## 5. 风险与缓解

### 5.1 潜在风险

| 风险 | 概率 | 严重性 | 缓解措施 |
|------|------|--------|---------|
| 模式 4 与 `el_select` 冲突 | 低 | 中 | `el_select` 模式在前（line 108），优先级更高 |
| 无引号模式误匹配按钮 | 低 | 中 | 使用后缀关键词（`Tab`/`标签`）作为锚点，无后缀不匹配 |
| `切换到` 与页面导航冲突 | 极低 | 低 | 限定必须有 Tab 后缀或引号 |
| 现有用例回归 | 极低 | 高 | 新增模式不覆盖现有模式，向后兼容 |

### 5.2 边界情况处理

#### 边界 1：`点击登录日志`（无后缀）

**行为**：匹配 `click_btn`（通用兜底）

**理由**：
- 无后缀无法判断是 Tab 还是按钮
- 用户应明确写出 `标签` 或 `按钮`

**示例**：
```python
('点击登录日志', 'click_btn'),  # 匹配通用 click_btn
```

---

#### 边界 2：`点击登录日志选项卡`

**行为**：匹配 `click_btn`（通用兜底）

**理由**：
- `选项卡` 属于 option-card 语义
- 方案 A 明确排除 `选项卡`

**示例**：
```python
('点击登录日志选项卡', 'click_btn'),  # 选项卡不属于 tab
```

---

#### 边界 3：`在"登录日志"标签页中选择"今天"`

**行为**：无匹配（不是 Tab 点击）

**理由**：
- 这是 option-card 语义（在某个区域中选择某个选项）
- 但 `选项卡` 被排除，所以不匹配 `option_card` 模式

**处理**：
- 用户应改写为 `在"登录日志"选项卡中选择"今天"`
- 或手动标注为 `l3_call`

**示例**：
```python
('在"登录日志"标签页中选择"今天"', 'unknown'),  # 无匹配
```

---

#### 边界 4：`切换到"登录日志"页面`

**行为**：无匹配（不是 Tab 点击）

**理由**：
- `页面` 不是 Tab 后缀
- 这是页面导航语义

**处理**：
- 用户应使用 `open_url` 或 `click_navigate`

**示例**：
```python
('切换到"登录日志"页面', 'unknown'),  # 无匹配
```

## 9. 附录：正则表达式详解

### 9.1 模式 1 正则

```python
rf'(?:点击|单击|点|切换到?|选择){Q}(.+?){Q}\s*(?:标签页?|tab页)\b'
```

**分解**：
- `(?:点击|单击|点|切换到?|选择)`：动词组（`切换到?` 匹配 `切换` 或 `切换到`）
- `{Q}`：引号字符类（`["""']`）
- `(.+?)`：捕获组 1（label，非贪婪）
- `{Q}`：闭合引号
- `\s*`：可选空白
- `(?:标签页?|tab页)`：后缀组（`标签`/`标签页`/`tab页`）
- `\b`：单词边界

---

### 9.2 模式 2 正则

```python
rf'(?:点击|单击|点)\s*([^{Q}]+?)\s*(?:[Tt]ab(?:页)?)\b'
```

**分解**：
- `(?:点击|单击|点)`：动词组（不含 `切换`/`选择`，避免与模式 3 冲突）
- `\s*`：可选空白
- `([^{Q}]+?)`：捕获组 1（label，非引号字符，非贪婪）
- `\s*`：可选空白
- `(?:[Tt]ab(?:页)?)`：后缀组（`Tab`/`tab`/`Tab页`/`tab页`）
- `\b`：单词边界

---

### 9.3 模式 4 正则

```python
rf'(?:切换到?|选择){Q}(.+?){Q}(?:\s*$|(?=，|,|；|;))'
```

**分解**：
- `(?:切换到?|选择)`：动词组（限定为 `切换`/`选择`，不含 `点击`）
- `{Q}`：开引号
- `(.+?)`：捕获组 1（label，非贪婪）
- `{Q}`：闭合引号
- `(?:\s*$|(?=，|,|；|;))`：边界断言
  - `\s*$`：行尾（可选空白）
  - `(?=，|,|；|;)`：或后跟标点（前瞻，不捕获）

**说明**：
- 不匹配 `点击`，因为 `点击"XX"` 可能是按钮
- 边界断言确保不会误匹配 `切换到"XX"页面`
